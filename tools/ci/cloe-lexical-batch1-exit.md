# CLOE-LEXICAL-BATCH1 PostgreSQL Lexical Population Exit

The dogfood `dynamic_default` dispatch implemented and independently
reviewed bounded use of the existing Psycopg cursor batch operation.
At most 64 rows and 1 MiB of UTF-8 string parameters go into a group.
A single oversized row uses its own group and retains database validation.
Document parents are sent before their chunks inside each existing
lease-fenced write transaction.

A disposable PostgreSQL trace over 19 documents,
55 chunks and 4 omissions recorded
88 frontend synchronization messages on the
incumbent route and 11 on the candidate route.
Both sent 86 binds and produced identical stored
rows, alias text and ranked and phrase vectors. This is a count of frontend
protocol messages for the named fixture.

A real duplicate chunk in a second document transaction rolled it back
while the earlier committed building batch remained available for owned
cleanup. A separate connection read the prior ranked hits while the first write
transaction was open. Cleanup removed the failed generation's rows and
the prior ranked generation retained query authority.

The combined frozen source passed 33 scoped unit and 32 scoped containerized integration cases. The retained Python, file-length, compilation, and Git diff checks passed.
