Find your way through a codebase.

Common Lore Index, or CLOE, maps how source files, scripts, configuration, and tests fit together. Follow a connection back to the file and line that explains it.

Find answers in the source

  • Where does it start?

    Trace a startup script to the program it launches and the configuration it loads along the way.

  • What else uses this?

    Follow imports and references across files so you know where to look before making a change.

  • What supports that connection?

    Inspect the source citation and use the confidence label to tell direct evidence from a heuristic.
